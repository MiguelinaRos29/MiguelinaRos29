# Hola, soy Migue 👋

Desarrolladora full stack y fundadora de [Open Consultech](https://www.openconsultech.net), una consultora tecnológica que da servicio a República Dominicana, Latinoamérica y el mercado hispano de EE. UU. Construyo aplicaciones web y móviles de principio a fin: base de datos, API, interfaz y despliegue.

## Proyectos destacados

- **[Mi Propio Style](https://github.com/MiguelinaRos29/mi-propio-style)**: e-market de moda con microservicios (FastAPI + React + PostgreSQL), JWT, compra completa con stock y emails de bajadas de precio. [Demo](https://mi-propio-style.vercel.app/)
- **[PaClases RD](https://paclasesrd.com)**: plataforma de comunicación escolar en producción (Next.js + Supabase) con asistencia, permisos, pagos, boletines y mensajería. Seguridad con RLS y rotación de claves.
- **[Lumina Mobile](https://github.com/MiguelinaRos29/lumina-mobile)**: app móvil con asistente de IA y gestión de citas (Expo + React Native).
